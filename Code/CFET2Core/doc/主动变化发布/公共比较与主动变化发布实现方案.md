# 公共比较与主动变化发布实现方案

日期：2026-10-10

状态：已实现并完成回归，尚未提交或发布。基于已实现的 [自动观察引用类型变化实现方案](../自动观察引用类型/自动观察引用类型变化实现方案.md)。本文保留方案说明，实际接口、路径边界与验证记录见第 9 节。

## 1 目标与范围

自动观察与组件主动变化发布使用同一套值快照和内容比较规则。提供组件一行调用的主动辅助函数，变化时发布 changed。开发者直接 Publish 的行为保持不变。

公共比较接口和主动发布辅助函数采用运行期类型校验。不支持的声明类型或实际类型抛出 NotSupportedException；调用代码可以编译通过，执行到对应调用时才报错。无需安装额外工具。

本阶段不增加 minDelta、自定义对象比较或参数化自动轮询。参数化主动事件路径是辅助函数的一部分，须复用 Get 的实际参数寻址规则，不能先按手工拼接格式实现。

## 2 当前基础与抽象

当前 ObservationValueSnapshot 为 Core 内部静态类，提供 Capture 和 ContentEquals；ResourceObservationTypePolicy 提供声明类型资格检查；ResourceObservationManager 已通过快照比较产生 changed；EventHub.TryPublish 返回是否接受本地入队。

已提供公共 ResourceValueComparison，接口如下：

```csharp
public static ResourceValueSnapshot Capture<T>(T value);
public static bool HasChanged(ResourceValueSnapshot previous, ResourceValueSnapshot current);
```

ResourceValueSnapshot 封装独立比较值，不向调用者暴露可变的内部容器。只允许框架通过内部接口复制出事件载荷。比较层不发布、不保存资源基准，也不把两个原始业务引用直接作为可靠历史值比较。

自动观察迁移到同一比较实现，保留初读不发布、共享观察和失败恢复语义。主动辅助函数另行持有状态，不与自动观察共用比较基准。

## 3 支持类型

- 原有标量：枚举、bool、char、整数、float、double、decimal、string、DateTime、DateTimeOffset、TimeSpan、Guid；值类型支持 Nullable。
- 数组：元素递归受支持，含多维和锯齿数组。
- 精确 List<T>：T 递归受支持。
- 精确 Dictionary<TKey, TValue>：键为原有标量或其 Nullable，值递归受支持。null 键遵循 Dictionary 自身限制。
- 不支持自定义 class/struct、容器子类、object、dynamic、接口声明及其他容器。List<object>、Dictionary<string, CustomType> 等嵌套不支持类型同样拒绝。

值参数传原始值，不接受 Status<T>/Config<T> 作为比较值。已有自动观察仍按样本中的 T 判断；主动调用者传 sample.Val 和 sample.Timestamp。这样不将样本元数据误当业务值比较。

数组及 List 比较顺序和内容；Dictionary 忽略插入顺序，保留键比较器并按双方键规则检查；标量沿用相等性。仅时间戳变化不触发发布。

## 4 主动辅助函数

已作为 Thing 的公共方法，解析实际挂载位置和资源声明名称：

```csharp
public bool PublishResourceIfChanged<T>(
    string resourceName,
    T value,
    object[] parameters = null,
    DateTimeOffset? timestamp = null);
```

调用示例：

```csharp
PublishResourceIfChanged(nameof(Temperature), temperature,
    parameters: new object[] { channel }, timestamp: sampledAt);
PublishResourceIfChanged(nameof(Channels), channels);
```

返回 true 表示 Core 接受本次 changed 入队，false 表示与已发布基准相同。路径、类型、参数、快照或发布状态错误抛出明确异常，不用 false 混淆失败。关闭期间无法入队时保持旧基准并报告发布失败。不表示远端已经收到。

流程：校验资源及值类型 → 解析完整参数化资源路径 → 获取该路径状态锁 → 捕获当前快照 → 比较 → 生成独立事件值 → TryPublish → 成功后保存新快照。

首次调用有效值即发布，包括类型明确的 null；自动观察初读仍不发布。不同完整参数化路径分别保存基准，同路径调用串行化比较、发布和更新。同一数据既自动观察又主动辅助发布可能各自产生事件，公共比较层不承担跨入口去重。

状态由当前 EventHub 持有，按注册资源实例与完整路径隔离；Hub 关闭时清理，不设随意淘汰的缓存容量。同一 Thing 换 Hub 或挂载位置时使用新资源实例，不复用旧基准。保留固定目录边界，不新增运行中资源移除或解除绑定接口。

## 5 运行期类型校验与缓存

公共 Capture<T> 与 PublishResourceIfChanged<T> 在捕获快照前校验声明类型 typeof(T) 和非 null 值的实际类型，递归检查数组元素、List 元素、Dictionary 键和值的类型。类型明确的 null 仍检查声明类型，不能通过 null 绕过不支持类型限制。

类型校验使用第 3 节的同一份白名单，与自动观察资格规则保持一致。泛型包装方法在运行时按已构造的实际 T 校验，不因使用泛型包装而拒绝。

```csharp
PublishResourceIfChanged(nameof(Value), new int[] { 1, 2 }); // 允许
PublishResourceIfChanged(nameof(Value), new List<int> { 1 }); // 允许
PublishResourceIfChanged(nameof(Value), new Dictionary<string, int[]> { ["a"] = new[] { 1 } }); // 允许

PublishResourceIfChanged(nameof(Value), new CustomData()); // 运行期 NotSupportedException
PublishResourceIfChanged(nameof(Value), new List<CustomData>()); // 运行期 NotSupportedException
object boxed = new int[] { 1 };
PublishResourceIfChanged(nameof(Value), boxed); // 声明类型 object 不支持，运行期抛异常
List<int> derived = new DerivedList();
PublishResourceIfChanged(nameof(Value), derived); // 实际容器子类不支持，运行期抛异常
```

dynamic 调用若成功绑定到目标泛型接口，按运行时确定的 T 和实际值执行相同检查；绑定失败由 C# 动态绑定机制报错。不能通过 dynamic 保证保留调用前的声明类型信息，也不承诺所有 dynamic 调用都会被类型校验拒绝。

### 5.1 异常信息

不支持类型抛出 NotSupportedException，包含声明类型或实际类型、不支持节点的类型，以及嵌套位置。辅助发布场景还包含解析后的完整资源路径；无法解析资源时按既有资源或参数错误报告，不伪造完整路径。公共比较接口不要求提供资源路径。

类型嵌套位置示例：List.Element、Dictionary.Key、Dictionary.Value.Array.Element；运行期复制元素时可补充元素索引等位置。失败发生在发布和比较基准更新之前。

资源标识和参数列表不按比较值白名单拒绝；资源、参数数量、编码及完整路径仍单独校验。

### 5.2 类型结果缓存与性能

使用线程安全、按 Type 索引的类型校验缓存，保存支持结果及不支持结果。不支持结果保存不可变的类型与相对嵌套位置描述，不缓存异常对象或资源路径；每次失败按当前调用上下文创建异常。

首次类型校验递归检查类型结构，后续直接查询缓存。此工作量取决于类型嵌套深度，与容器元素数量无关。缓存不保存值、快照或比较基准，也不能以声明类型通过代替实际类型检查。

容器复制过程中同步校验各非 null 元素的实际类型，查询同一缓存，不增加一次独立的元素遍历。标量采用快速路径。快照复制和内容比较仍随容器内容规模增长，不保证具体耗时；容器读取一致性由业务同步保证。

## 6 运行期错误与兼容

公共比较与主动辅助函数遇到不支持声明类型或实际值时，按第 5 节抛出包含类型、嵌套位置及适用资源路径的 NotSupportedException；快照失败保留内部原因。失败不发布、不更新基准。不要自动降级为直接 Publish，否则会失去调用者要求的变化判定。

直接 Publish 仍接受原来可发布的业务载荷，不套用新的比较类型检查。复杂类型资源仍可按既有规则普通读取或主动发布；本方案的运行期异常针对显式调用公共比较或变化发布 API。自动观察继续保留已有建立结果及运行期诊断方式。

保留独立事件值与比较基准；业务对象和订阅者的修改不污染基准。容器并发读取一致性仍由组件同步保证。

4. 接入声明类型与实际类型校验、线程安全类型结果缓存和上下文异常信息。

验收至少包括：

- 原有标量、Nullable、三类容器、嵌套容器均可调用；自定义对象、嵌套不支持类型、容器子类、object 和接口声明在调用时抛出 NotSupportedException；不支持类型的 null 同样拒绝。泛型包装按运行时 T 校验，dynamic 按实际绑定结果处理。
- 验证异常类型及信息，覆盖声明类型、实际容器子类、深层嵌套位置和辅助发布完整资源路径；不支持类型的调用能够编译，但执行时失败。
- 验证支持与不支持类型均缓存、并发查询结果一致、不同资源失败信息不串用；元素实际类型检查与复制共用一次遍历。
- 首次有效值发布，相同内容不发布，原地修改发布，通道之间独立基准。
- 类型校验、快照或入队失败均不发布新事件、不更新基准、不降级为直接 Publish；后续有效调用能够恢复；并发同路径不重复发布相同值。
- 发布值保持类型与独立性；保留源端时间戳；直接 Publish 行为不变。
- Hub 关闭、Thing 换 Hub/挂载位置时清理或隔离旧状态。

## 9 实现与回归记录

### 9.1 公共比较

实际公共类型位于 Jtext103.CFET2.Core.Event：ResourceValueComparison 和 ResourceValueSnapshot。快照构造及内部值均不向业务公开，HasChanged 的两个快照参数不能为 null；要比较 null 值须先 Capture<string>(null) 等捕获类型明确的值。

类型资格由 ValueTypeValidation 的线程安全缓存统一管理，自动观察与公共比较使用同一规则。缓存支持结果及不支持节点信息，不缓存异常或资源路径。复制嵌套容器时同步校验实际类型。自动观察仍保留原有 Skipped/Failed 与运行期诊断契约。

### 9.2 参数路径与生命周期

Thing.PublishResourceIfChanged 使用声明名称或注册别名定位当前 Thing 的 Status/Config，不执行 getter。调用参数复用 MapInputParameters；拒绝多余参数，补齐默认值，展开 params。数值按 InvariantCulture 格式化，字符串原样，其他值尝试既有 JSON 表示；生成结果经 ParseLocalRequest 和参数映射验证。不能按现有 Get 转换规则还原的参数抛 ArgumentException，不发布。

按用户确认，参数不包含 /，不新增百分号编码或解码。null、空参数片段及不能往返的表示不支持。参数转换仍沿用 Get 的现有行为，包括其文化设置；不能往返的格式明确拒绝。共用映射器补齐了零元素 params 的读取能力，不改变其他 URI 规则。

状态由 EventHub 按注册资源实例与完整路径管理，同一 Thing 新挂载生成新资源实例，因此隔离旧基准。路径参数比较区分大小写。关闭 EventHub 时清空状态；Thing 的 Hub 保存创建时的宿主引用，旧 Hub 不会转而向新实例发布。未注册 Thing 抛 InvalidOperationException，关闭或拒绝入队抛 ObjectDisposedException。

公共辅助函数检查所传值的类型；不要求它与 getter 返回声明完全相同。传 sample.Val 与 sample.Timestamp，不能传整个 Status/Config 作为比较值。首次有效值发布，相同内容返回 false；失败保留基准。直接 Publish 不应用这些检查。

### 9.3 可调用示例

```csharp
using System;
using Jtext103.CFET2.Core;
using Jtext103.CFET2.Core.Attributes;
using Jtext103.CFET2.Core.Event;

public class TemperatureThing : Thing
{
    [Cfet2Status, Cfet2Event]
    public double Temperature(int channel) => ReadTemperature(channel);

    public void OnSample(int channel, double value, DateTimeOffset sampledAt)
    {
        PublishResourceIfChanged(nameof(Temperature), value,
            parameters: new object[] { channel }, timestamp: sampledAt);
    }

    private double ReadTemperature(int channel) => 0; // 替换为组件实际读取实现
}

```

无资源发布需求时，可在业务方法内单独复用公共比较（需要 System.Collections.Generic 和 Jtext103.CFET2.Core.Event）：

```csharp
var values = new List<int> { 1 };
var baseline = ResourceValueComparison.Capture(values);
values[0] = 2;
bool changed = ResourceValueComparison.HasChanged(
    baseline, ResourceValueComparison.Capture(values)); // true
```

两个代码片段分别用于组件声明和业务方法中的调用代码。不要求每次 Set 发布事件，组件可在实际采样或更新位置调用。通道 1 的完整来源路径为 /挂载位置/Temperature/1，通道之间独立比较。

## 2026-10-12 订阅契约更新

本阶段不改变辅助函数的参数化 Source 和发布比较规则。新的 [订阅使用设计文档](../订阅使用/订阅使用设计文档.md) 规定：所有含参数 getter（含默认参数和 params）不自动观察；SubscribeResource 可带参初读一次并按调用者指定路径字面匹配，不规范化或补写事件订阅地址；WS 含参数基础路径只登记事件接收需求，不初读。

开发者须明确使订阅路径与本辅助函数实际发布 Source 一致。例如辅助函数省略默认参数时发布 /Default/7，SubscribeResource('/Default') 虽可读取默认值，但仍只匹配 /Default；应显式订阅 /Default/7。前文测试记录属于 10 月 10 日对应实现阶段。
